# Feasibility Audit — Master Prompt #4

**Audit date:** 2026-08-18 UTC
**Purpose:** নতুন data layer কোড করার আগে public/affordable access, update cadence, request constraints, GitHub Actions suitability এবং historical validation coverage যাচাই করা।

> **Scope boundary:** “API endpoint আছে” এবং “honest point-in-time backtest dataset আছে”—এই দুটি একই দাবি নয়। যেখানে current data পাওয়া যায় কিন্তু historical depth বা point-in-time replay নিশ্চিত নয়, সেখানে implementation context-only এবং report-এ সেই limitation বহাল থাকবে।

## What was implemented

The repository now implements a conservative context layer in `src/signalbot/context.py` and `src/signalbot/fusion.py`. The runtime scanner collects public Binance derivatives context, a bounded exchange order-book snapshot, and optional CoinGecko/DefiLlama/FRED macro context. Each field is nullable, every source has provenance metadata, and a failed provider cannot be converted into a fake neutral observation without being recorded as missing.

The signal path remains deliberately conservative. Legacy EMA/RSI/MACD/volume logic supplies a candidate direction, but `require_context: true` and a minimum feature-coverage threshold prevent notifications when the orthogonal context is absent. This is a **hybrid context-gated research architecture**, not a claim that the previous retail-indicator edge has been repaired.

## Explicitly not implemented by default

Wallet-labelled exchange netflow, whale alerts, issuer-level mint/burn attribution, a historical L2/order-flow archive, a paid institutional derivatives history, and a trained production ML model are not included. These omissions are deliberate: implementing them without verifiable access and point-in-time historical data would create a more impressive-looking but less honest system.
